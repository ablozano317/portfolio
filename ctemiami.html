CTE & Esports

Role: Designer

A professional design project for an educational esports program.

Project overview

This project focuses on the design of a website for an educational esports program, presenting career and technical education alongside esports.

Ideation

The page brings the educational program and esports together in a professional web experience. The project graphic supports the program's visual identity. The main visual inspiration was drawn from gradients, gaming lounges, futuristic elements, and cool blues and violets to create a modern and engaging aesthetic.

Challenges

- The design needed to communicate both the educational and esports aspects of the program while maintaining a clear, professional presentation for students, families, and educators.
- Balancing the visual appeal of esports with the educational content to ensure the site was engaging yet informative.
- Being that this was my first time using Beaver Builder and WordPress for a Project, there was a learning curve adjusting to it.
- Ensuring the website was accessible and user-friendly for all potential visitors.

Results

The project presents CTE and esports together in a dedicated web experience and gives visitors a place to explore the program. The website was deployed an continues to draw visitors and engagement.
